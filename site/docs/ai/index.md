# AI

The AI stack provides local model hosting, chat interfaces, transcription, and text-to-speech — all self-hosted.

| Service | Purpose |
|---|---|
| [Hermes](./hermes) | AI agent gateway + workspace UI |
| [Open WebUI](./open-web-ui) | Chat interface backed by Hermes |
| [Ollama](./ollama) | Local LLM hosting |
| [WhisperX](./whisperx) | Speech-to-text transcription + speaker diarization |
| [Chatterbox](./chatterbox) | Text-to-speech |
| [ComfyUI](./comfyui) | Node-based image generation |
| [MCP](./mcp) | Playwright browser automation for agents |
| [Firecrawl](./firecrawl) | Web scraping and crawling API for agents |
| [Honcho](./honcho) | Cross-session memory for Hermes |
| [OpenViking](./openviking) | Context database — memory, resources, and skills |
| [wyoming-whisper](./wyoming-whisper) | Speech to text for Home Assistant voice, on CPU |
| [wyoming-piper](./wyoming-piper) | Text to speech for Home Assistant voice, on CPU |
